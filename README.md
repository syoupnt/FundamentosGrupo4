# Sistema Mesa de Partes Digital - ONPE

Este repositorio contiene una pequeña aplicación en Python para simular el registro de trámites en una mesa de partes digital, como una práctica de fundamentos de programación. El sistema permite registrar ciudadanos, validar datos, asignar un expediente y generar un reporte diario de cierre.

## Estructura del repositorio

- `main.py`: programa principal con la lógica del sistema
- `pseudocodigo/`: versión en pseudocódigo del algoritmo, en formato `.psc`

## Cómo ejecutar

1. Abre una terminal en la raíz del proyecto.
2. Ejecuta el siguiente comando:

```bash
python main.py
```

## Pseudocódigo

La carpeta `pseudocodigo` incluye la lógica del programa representada con un algoritmo estructurado, útil para entender el diseño antes de escribir el código Python.
